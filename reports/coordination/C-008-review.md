# C-008 검토 / C-009: 생성·검증 모델 역량 교체

600건 조립은 목표달성이 아니다. 120건 중 의미정답52건이라는 품질실패 보고를 채택하고 전체산출물을보류한다. 작은2.1B생성기+1.7B검증기의실패를정규식추가만으로해결하거나과제를단순값두개추출로축소하지않는다. 자체TRID모델크기목표와학습자료작성용교사모델크기는별개다.

## 즉시 실행 승인
- AWS에서 더 강한 공개가중치 교사·검증 모델을 사용한다. 최소32B급 한국어/추론 가능한 모델을 우선 검토하고 서로다른모델로생성/독립검증한다. 공개가중치 접근가능성·모델/합성데이터사용조건·메모리·추론지원 확인후 적합한GPU를확보한다. 비용재승인불필요. 외부모델가중치는TRID제품에섞지않는다. 모델/리비전/양자화/프롬프트/사용조건근거를기록한다. A/B 자원 변경금지.
- 기존 작은모델로9000건을더생성하지않는다. 먼저 알려진실패사례와별도의새문서로6유형각10건을실행해모델·생성·검증경로를확인한다. 실패사례는개발용,이후독립검토표본에는섞지않는다.
- 질문은완성된근거와정답범위를보고작성하되답을질문에노출하지않는다. 질문과답이공통핵심어를포함한다는이유만으로제거하지않는다. 다중근거는한결론을위한복수근거추론을요구하고무관한사실병렬나열로대체하지않는다.
- 수치변화는제목·본문·합계·비율·단위의일관성을검증한다. 숫자1회등장만으로독립성을판정하지않는다. 안전하게반사실편집할수없는문서는건너뛰고원문/편집해시와편집내용을보존한다.
- 표는실제머리글계층과행·열조건을보존해정답유일성을판정한다. 모호한표는격리할수있지만전체유형을쉬운문제로바꾸어품질상승이라고주장하지않는다.
- 검증모델은초안답을보기전근거로독립답변을만들고후속비교에서대상·조건·단위·완전성·복수정답·논리적지지여부를판정한다. 생성/검증역할·실패/잘림/미처리를기록한다.
