# SITE-MIGRATION-013 — Docker 정상 종료(사용자 승인) 후 맥미니 이관 시도

**상태: 차단. 질의 부하에서 물리 메모리가 부족하다.**
- Docker 정상 종료는 **부분 성공**이다. VM은 종료됐고, 앱 UI와 backend 3개는 남았다.
- 최소 구성(기본 1.7B + 독해기)은 기동과 180초 유휴는 통과했다. 그러나 **업무 질문 처리 중 압력 2**가 났다.
- 그래서 이관, 전 기능(5버전) 시험, 터널 전환, 맥북 정지 외부 검증은 하지 않았다.
- 원점은 맥북 그대로다. 강제 종료, kill, 재부팅, 삭제, 설정 변경은 없다.

**영향**
- Docker의 13개 공개 포트는 무응답에서 연결 거부로 바뀌었다(nc 실패). 컨테이너는 VM과 함께 멈췄다.
- 컨테이너, 볼륨, 이미지는 손대지 않았다.
- 다른 서비스는 전부 같은 상태다(아래 표).

**종료 전후 (VM 종료분)**

| 시각 | 압력 | free% | 스왑 | free | active | inactive | 압축기 물리 |
|---|---|---|---|---|---|---|---|
| 16:51:59 (전) | 1 | 59% | 8,641MB | 0.09GB | 4.57GB | 2.81GB | 3.48GB |
| 16:59:34 (후) | 1 | 60% | **6,053MB** | 0.88GB | 4.28GB | 3.57GB | 3.29GB |

- 회수: 스왑 −2.6GB. 물리는 free + inactive 약 +1.5GB, 압축기 −0.2GB.
- VM의 8.1G footprint는 대부분 압축이나 스왑 상태였다. 그래서 물리 회수가 작다.
- 남은 `com.docker.backend` 1120은 여전히 MEM 3.5G(대부분 압축)이다.

## 3. TRID 단계 시험 (배포판 9256df4, 이전과 같은 계측)

**① 최소 구성 기동과 유휴 (16:59–17:02): 통과**
- 12초에 ready. 180초 동안 압력은 계속 1이었다.
- 대가:
  - free%는 60%에서 37%로 내려갔다.
  - wired가 2.76GB에서 4.93GB로 늘었다. llama-server Metal 버퍼로 보인다 [추정].
  - 압축기 물리가 3.28GB에서 4.74GB로 늘었다.
  - TRID RSS는 4.72GB에서 2.88GB로 줄었다. 유휴 페이지가 압축됐다.

**② 질의 부하 (17:03:38–17:04:00): 차단**
- 로컬에서 브라우저와 같은 방식으로 질의했다: 비밀키 헤더, 세션 쿠키, CSRF.

| 버전 | 질문 | 결과 |
|---|---|---|
| 기본 1.7B | 안녕 | 200, 1.2초, 대화 응답 |
| 기본 1.7B | 한국부동산원 여비규정에서 일비는 어떻게 지급하나요? | 200, 10.9초, 한국부동산원 여비규정 적용, 해설만(unverified) |
| v0.1 독해기 | 공무원 국내 출장 숙박비 상한은 어떻게 정해져 있나요? | 200, 0.5초, not_found |

- 1초 압력 표본: 1이 5회, **2가 9회.** 17:03:49(업무 질문 처리 중)부터 2였고, 17:04:00에도 2였다(free 33%, wired 5.00GB, 압축기 물리 5.21GB).
- 17:04:10에 본인 시험만 정지했다. 30초 동안 압력 1을 유지했고, 17:04:40에 free 55%, 다른 서비스는 전부 기준과 같았다. 맥미니에 본인 프로세스는 남아 있지 않다.

**결론**
- Docker VM 종료로 물리 RAM이 약 1.5GB 늘었다.
- 하지만 질의 시 임베딩 + 1.7B 생성 부하에서 wired와 압축기가 늘어 압력 2가 된다.
- 최소 구성도 질의 부하 기준을 통과하지 못했다. 그래서 5버전 전 기능 시험은 할 조건이 없었다.

**관찰(이관과 무관, 배포판 동작):**
- 같은 세션에서 한국부동산원 질문 다음에 물은 "공무원 국내 출장 숙박비" 독해기 질의가 한국부동산원 규정을 적용해 not_found였다.
- 대화 맥락이 기관을 이어받은 것으로 보인다 [추정]. 검색 담당 검토 대상으로 넘긴다.

## 4. 현재 상태

- **test.tridatum.co:** 맥북 원점 그대로(launchd + 고정 named tunnel). Worker는 바꾸지 않았다.
