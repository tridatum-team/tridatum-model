| | ④ 파생 파일 계약 `trid/service/derived.py` | 아래 |

**파생 파일 계약 (023 검토 요구 반영)**
- 생산자는 원본 sha256을 만들기 전과 후에 재고, 다르면 설치하지 않고 오류를 낸다.
- 사본은 임시 파일에 쓰고 원자적으로 교체한다. 기록(`*.json`)도 원자적으로 교체하며, 원본과 사본 두 sha256을 함께 기록한다.
- 소비자는 기록이 파싱되고 두 sha256이 지금 파일과 맞고, dense는 dtype과 shape도 맞을 때만 사본을 쓴다. 없음, 오래됨, 덜 쓰임, 손상, 기록 손상 모두 원본을 예전 방식으로 읽는다. 유효한 f16·json으로 서비스 시작이 깨지지 않는다.
- 022의 타입 고정 테스트는 지웠다. 소비자 동작 테스트 `tests/test_service_derived.py`로 바꿨다(현재, 오래됨, 절반 잘림, 기록 손상, 생산 중 원본 변경 → 원본과 같은 벡터·문서·내적).
- 시도했다가 버린 것: Workspace 초기화 순서 변경(검토 파일을 색인보다 먼저 읽기). 측정 차이가 없어 원래 순서와 오류 동작을 유지했다.

## 7. 남은 제약 (사실대로)

- **디스플레이 깨움 여유:**
  - 정상 상태 여유는 늘었다(free + inactive +0.2GB, 압축기 −0.5GB, 백엔드 footprint −0.6GB, 기동 최고치 −1.0GB).
  - 그러나 디스플레이가 꺼진 상태에서 켜지고 배경화면 동영상이 재생되는 순간(022: wired +1.48GB)은 023 코드로 직접 재현하지 못했다. SSH `caffeinate -u`로는 일어나지 않았고, 설정 변경으로 강제하지 않았다.
  - 이 이벤트로 압력 2가 30초 이상 이어질 가능성은 남아 있다.
- **성능:** CPU라서 기관 질문 약 17–21초다(맥북 Metal 9–13초).
- **품질(연결과 별개):** 같은 세션 기관 전환에서 이전 기관 규정이 이어짐. 첨부 문서 답은 해설만이거나 근거 못 찾음.
- **맥미니 전제:** bohun-test 정지(재로그인 시 다시 뜸), Docker VM 정지. 이 둘이 다시 켜지면 여유가 줄어든다.
- **코드 관리:** 운영 코드는 브랜치 `site-memory-022`(`6a5eb37`)이며 main에 병합하지 않았다. 병합 시점은 총괄 결정이다(ROOT-009와 분리 유지).
- 맥미니 재부팅 시험은 하지 않았다(SFT controller 위험). 자동 로그인 설정상 재부팅 후 두 TRID 작업이 뜬다.
