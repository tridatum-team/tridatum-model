# B-004 검토 / B-005

같은 검사기·같은 표본 짝 비교와 실제 AWS clean-v2 완료 보고를 채택한다. clean-v3는 실행 중이며 아직 train-ready 승인하지 않는다. B-003의 접속 복구와 독립 진행한다.

1. 실행 중 clean-v3 파일럿을 완료하고 manifest/해시 및 저장된 실제 결과의 같은 표본 재검증을 보고한다. 로컬 raw 재처리 결과와 AWS 산출물을 혼동하지 않는다.
2. 개인정보 정책: 개인 연결 가능성이 있는 050 안심번호는 기존 redact 경로에서 처리한다. 공개 대표번호를 모두 개인정보라고 주장하지 않는다. 080/060/070 및 해외번호는 문맥과 정책을 명시하되, 개인 여부가 불명확한 연락처는 보수적으로 치환/격리한다. A에 공유 함수 변경을 먼저 통지하고 기존 학습 입력은 바꾸지 않는다.
3. URL aid 및 학원등록번호 오탐은 해당 문자열만 예외 처리하지 말고 탐지기·구조·문맥 원인을 분석한다. 숫자열이 URL 쿼리에 있다는 이유만으로 모든 개인정보 검사를 면제하지 않는다. 적법한 식별자 보존과 실제 개인정보 마스킹을 함께 검증한다. 안전하게 구분할 수 없으면 불명확한 행을 격리하고 오탐 한계를 명시한다.
4. 기계번역/SEO 문제는 실제 실패 사례를 추가 분산 표본에서 조사하고, 정상 번역·정책 문서를 단순 문체로 제거하지 않는다. 신뢰할 수 있는 규칙이 없으면 불확실 출처/문서를 격리하고 보류 사유를 기록한다. 작은 AI 표본으로 전체 품질이나 오류율을 주장하지 않는다.
5. 수정된 후보에 대해 같은 표본의 개인정보 잔존/정상 숫자 손상/정상 공공문서 오탐을 재검증한다. 파일럿 반복 전에 로컬 재현과 수정 검증을 끝내 불필요한 전체 재처리를 피한다. AWS 필요한 실행은 승인하되 나머지24파일 확대는 검토 후 결정한다.
6. 확보148계열과 일치0은 부분 검사다. 852계열 미확보 상태에서 예약기관8971행 격리 해제 금지.
