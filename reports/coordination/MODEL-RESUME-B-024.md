## 2. 사례 구조와 기록 항목

**행 형식:** 기존 case view와 같다.
- `question`, `context`(D1…Dn), `target`(문장마다 `[Dn]`), `behavior`, `time_label`, `doc`.
- D1 첫 줄은 `자료 정보: 기관 「제목」 (문서 id) · 기준 YYYY-MM-DD 시행 조문(이후 개정 여부 미확인)`이다.

**`candidate` 필드**

| 키 | 내용 |
|---|---|
| `structure` | 결론, 조건 `[[설명, 원문 구간]]`, 예외, 주체(원문 구간 선택), 되물을 사실, 보류 사유 |
| `source` | 문서 id·제목·종류·URL·이용허락(저작권법 제7조, law.go.kr)·본문 sha256·조문별 문자 위치(char_start/end) |
| `time` | 시행일(법령은 원문 XML 시행일자, 행정규칙은 색인 meta effective_date). "현행 표시 안 함" |
| `family` | 가족명(시행령·시행규칙 → 법률), 기존 case view 문서 여부. 33행 모두 기존 view와 다른 문서다 |
| `pii` | 개인정보 힌트 0건(문서 id·날짜를 지운 뒤 `PII_HINT`) |
| `review` | "B (AI) 작성, 기계 검사만, 사람 검수·품질 확정·학습 승인 아님" |

- **split:** 모든 행이 `split: candidate`다. A가 학습 분할을 정하기 전까지 train으로 쓰지 않는다.

- 제목이 언급됐다는 것만으로 혼입이라고 단정할 수는 없다. 판정은 C의 몫이다. B는 해당 view를 바꾸지 않았다.

## 6. 한계

- **작성자:** 질문·목표·구조를 B(AI) 한 명이 썼다. 검사는 원문 구간·숫자·인용의 기계 검사다. 결론의 법적 정확성은 사람 검수를 받지 않았다.
- **시점:** 모든 문서가 수집 시점 기준이다.
  - 농관원 상시출장 별표는 2018-07-01 시행 훈령이다(단가는 2014년 부칙으로 적용).
  - 상위 「공무원 여비 규정」 별표 8은 그 뒤 개정됐다(2025-10-01). 이 가족은 평가 노출이라 근거로 쓰지 않았고, 목표 문장에도 "이후 개정 여부 확인 불가"라고 적었다.
- **가족 판정:** 가족 판정은 제목 규칙(시행령·시행규칙 → 법률, 특례 접두사 제거)이다. 상위 법률을 인용만 하는 규정(예산성과금 규정 → 국가재정법, 물품관리 사무처리규정 → 물품관리법)은 걸러지지 않으며, C 보고에 별도로 적었다.
- **분포:** 되묻기 2건, 보류 5건으로 행동 유형이 고르지 않다. 법령은 1건, 행정규칙은 8건이다. 기관 자체 규정은 이번에 0건이다.
