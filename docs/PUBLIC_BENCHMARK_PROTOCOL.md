# 공공업무 성능 평가 확대 규격 (BENCHMARK-SCALE-001)

## 결정과 현재 상태

사용자는 반복되는 30문항 평가가 의미 있는 성능 결론을 내리기에 부족하다고 지적했다. 10~30문항은 실행·형식·실패 유형 점검에만 사용하고, 모델 우위나 전체 오류율 판단에 사용하지 않는다.

첫 공공업무 성능 벤치마크 목표는 **2,000문항**이다. 이는 현재 확보·검수 완료된 문항 수가 아니다. 문서 다양성, 오염 제거, 정답 검수를 통과한 문항만 센다. 숫자를 채우기 위해 템플릿 반복·패러프레이즈·지어낸 기관 문서를 추가하지 않는다. 2,000개가 무조건 충분하다는 주장도 하지 않는다. 실제 비교군 간 불일치율·문서 군집·기대 개선폭을 근거로 검정력을 다시 산정한다.

최종 시험의 문서 선정·정답·채점 규칙 소유자는 총괄이다. A/C 학습 담당에게 최종 정답이나 문항별 피드백을 제공하지 않는다. C는 평가 실행 경로와 개발 자료로 하네스를 검증하고, 최종 시험 제작·검수는 학습 담당과 분리한다. 중립적 검수 인력/독립 평가 실행자가 확보되지 않은 경우 그 상태를 차단 사항으로 명시한다. AI 작성·AI 검토만 거친 후보는 공공업무 전문가 검수 완료 골드셋이 아니다.

## 과제별 목표 구성

| 주 과제 | 문항 |
|---|---:|
| 사실·금액·날짜 추출 | 200 |
| 자격·신청·적용 조건 | 300 |
| 예외·제외 조항 | 200 |
| 표 해석·계산 | 250 |
| 여러 문단·문서 근거 결합 | 250 |
| 개정·시점·유효 규정 | 200 |
| 근거 기반 설명 | 200 |
| 근거 없음 | 200 |
| 근거 충돌 | 200 |
| 합계 | 2,000 |

답 있음 1,600, 근거 없음/충돌 400을 분리 집계한다. 각 문항은 하나의 주 과제와 복수의 보조 태그를 가진다. 설명 정확성은 설명 200개만 아니라 설명을 요구하는 모든 문항에서 별도로 평가한다.

보훈·복지, 주거·부동산, 고용·인사, 계약·조달, 회계·예산, 보건·안전, 교육·연구, 공기업 운영·서비스 등 8개 업무군을 목표로 한다. 각 군 최소 150문항, 한 군 최대 400문항으로 특정 분야 집중을 막는다. 기관 유형·업무군·문서 유형별 실측 분포를 공개한다. 한 출처의 보도자료만으로 구성하지 않고 규정·공고·업무편람·서식/표 등을 포함한다. 확보 못한 업무군은 빈칸으로 보고하며 다른 군 문항으로 조용히 대체하지 않는다.

## 문서 독립성과 누출 방지

- 최종 시험 예약 문서와 문서 계열·개정본·첨부·중복 묶음을 학습/개발에서 제외한다. 평가 생성 전에 예약한다.
- 동일 문서 계열을 주 근거로 하는 문항은 최대 2개를 원칙으로 하고 다중문서 문항은 모든 근거 문서를 기록한다. 공통 근거를 공유하는 문항은 독립으로 취급하지 않는다. 고유 근거 문서 목표는 최소 1,000건이지만 문서 수만으로 통계적 독립성을 선언하지 않는다.
- 기관 단위 및 시점 단위 미노출 구간을 별도 표시한다. 문서 텍스트 exact/near 중복과 학습 데이터 해시를 비교한다. 반복 사용한 RAG310/KLUE와 기존 30문항 파일럿은 최종 시험에 넣지 않는다.
- 평가 원문 제외를 위한 ID/해시 매니페스트는 총괄이 관리한다. n-gram 해시는 평가셋 암호화가 아니며 정답 비밀성을 보장하지 않는다.
- 최종 점수를 보고 하이퍼파라미터를 선택했다면 그 시험은 이후 개발 자료로 간주하고 새 독립 시험을 준비한다.

## 정답과 설명 채점

각 문항에는 원문 URL·기관·발행/적용 시점·사용권·원본 해시·근거 위치, 질문, 허용 정답/숫자 단위, 필수 조건·예외, 인용 대상, 과제 태그, 작성/검수 이력을 보존한다. 계산은 입력 근거와 계산식을 별도로 기록한다. 충돌·답 없음은 왜 답을 확정할 수 없는지 판정 근거가 있어야 한다.

골드 작성/검수는 비교할 후보의 출력을 보기 전에 수행한다. 기관 전문 지식이 필요한 경계 사례와 설명 정답은 공공업무 전문가 검수가 필요하다. AI 교차 검수는 선별 수단이지 사람 검수 대체라고 표시하지 않는다. 판정 불확실 문항은 고치거나 제외하고 그 수를 보고한다.

- 주지표: 답 있음 1,600문항의 의미적 결론 정확도. 값·단위·필수 조건을 만족해야 하며 정답 문자열 하나를 언급했더라도 모순된 추가 주장으로 결론을 훼손하면 정답이 아니다.
- 별도 지표: 인용 지지, 조건/예외 누락, 허위 추가 주장, 답 있는데 보류, 답 없는데 답함, 충돌 탐지, 형식 준수, 설명 루브릭.
- RAG310의 `값 [Dn]` 형식 점수와 자유 설명 의미 점수를 혼합하지 않는다. 정확한 서술형 답변을 단순 형식 차이로 오답 처리하여 기준선 성능을 낮추지 않는다.
- 기관/업무/과제별 점수와 문항 수를 함께 공개한다. 소표본 하위 그룹의 순위를 확정적으로 말하지 않는다.

## 공정한 비교와 통계

Qwen3-1.7B, Kanana-1.5-2.1B 및 기존 도메인 튜닝 기준선을 명시적 시작 비교군으로 한다. 실제 버전·파라미터·가중치 해시·튜닝 데이터·양자화·템플릿·생성 한도·실행 환경을 고정하고 모델별 정식 대화 템플릿을 사용한다. 같은 근거/질문을 제공하며 형식·decoder 차이에 따른 이득을 별도 보고한다. 공개 모델의 과거 학습 데이터 노출이 미확인이라는 한계를 명시한다.

모델 독해 평가와 동일 문서 집합의 검색 포함 서비스 평가를 분리한다. 정확도와 함께 메모리, 지연시간, CPU 실측, 폐쇄망 동작을 기록한다.

- 같은 문항의 paired 개선/악화와 95% 신뢰구간을 제공한다. 문서 계열을 군집 단위로 하는 bootstrap 등 상관을 반영한 분석을 주로 사용한다. 독립성 가정이 맞는 경우에만 일반적인 문항별 McNemar 결과를 그대로 해석한다.
- 단일 주요 비교/지표를 먼저 고정하고 여러 모델·과제의 유의성 검정을 할 때 다중비교를 보정한다. 통계적 유의성과 실제 개선 폭을 모두 보고한다.
- 50% 정확도, 독립 무작위 이진 문항이라는 단순 가정에서 95% 오차폭 근사는 n=30에서 ±17.9%p, n=2,000에서 ±2.2%p다. 이는 표본 수 설명용이며 위험 기반 30문항이나 실제 군집 평가의 신뢰구간이 아니다.
- 실제 도입 합격선과 허용 위험은 최종 시험 실행 전에 고정한다. A의 RAG310 개발 확대 기준을 최종 제품 도입 기준으로 재사용하지 않는다.

## 현재 세션에 내리는 실행 지시

- A: 기존 20M 안정성 파일럿은 계속한다. 소표본/학습 loss로 모델 우위를 선언하지 않는다. 평가 예약 문서 제외 계약 및 재현 가능한 체크포인트를 준비한다.
- B: B-002에 8개 업무군과 문서 유형별 후보 인벤토리/학습 제외 예약 가능한 문서 계열 ID를 포함한다. 총괄이 예약할 때까지 최종 시험 후보를 전량 학습에 투입하지 않는다. 최종 정답은 만들거나 공유하지 않는다.
- C: C-003의 10문항 실제 생성은 실행 스모크로 끝내며 우위 판단에 사용하지 않는다. 평가 하네스가 대규모 문항을 누락 없이 처리하고, 재개/출력 원본/모델별 실패·잘림을 기록하도록 점검한다. 신규 대규모 최종 문항·정답 작성은 맡지 않는다. 하네스 변경은 기존 개발 자료로 검증한다.
- 총괄: 각 세션 보고에서 문서 커버리지와 평가 실행 용량을 검토하고 최종 시험 예약·독립 제작/검수·실행을 분리 배정한다. 아직 없는 문항이나 전문가 검수를 완료했다고 보고하지 않는다.
